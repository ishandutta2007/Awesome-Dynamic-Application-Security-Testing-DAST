# Awesome-Dynamic-Application-Security-Testing-DAST

Top Dynamic Application Security Testing (DAST) Tools EcosystemCurated List of SaaS Products & Open-Source GitHub ProjectsFocused on Web Application & API Vulnerability Scanning, Automation & DevSecOps IntegrationLast updated: October 2026This repository tracks notable SaaS platforms and open-source projects for Dynamic Application Security Testing (DAST). These tools simulate attacks against running web applications and APIs to identify security vulnerabilities such as injection flaws, broken authentication, and misconfigurations without access to source code.Examples include Burp Suite Professional, Acunetix, Invicti (Netsparker), Fortify WebInspect, Veracode DAST, Rapid7 InsightAppSec, Checkmarx DAST, Synopsys WhiteHat, and AppCheck (the category leaders).Open-source emphasis: This section is heavily expanded with every major active project for self-hosting, CI/CD pipeline integration, and custom security automation — ideal for security teams, DevSecOps engineers, and researchers building transparent application security testing workflows. The open-source DAST landscape is anchored by OWASP ZAP (now maintained by Checkmarx as "ZAP by Checkmarx") , with a growing ecosystem of API-focused and template-driven scanners.-8Contributions welcome!
